From your Mac to the board in four steps.

No proxy, no API keys, no browser extension. The numbers come from files your tools already write.

  1. 1

    Run the menubar app

    One command starts it. It lives in the menubar, launches at login and syncs every hour.

  2. 2

    Collect locally

    The bundled open-source tokscale engine reads each tool's local usage logs and prices them. This step never touches the network with your data.

  3. 3

    Send daily aggregates

    One row per day, tool and model: token counts and API-equivalent cost. Nothing else.

  4. 4

    Climb the board

    Sign in with GitHub to see where you rank today, this week or all time, and open anyone's stats.

Works with the tools you already use.

Each tool keeps its own local logs. leaderborder reads them all and ranks the total.

Install in one line.

macOS on Apple silicon or Intel. The npm route needs Node 22 or newer.

npx leaderborder

Starts the menubar app and walks you through GitHub sign-in.

  • Global npm
    npm i -g leaderborder
  • Homebrew CLI
    brew install xaverric/tap/leaderborder
  • Homebrew app
    brew install --cask xaverric/tap/leaderborder
